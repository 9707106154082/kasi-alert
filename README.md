# StudyLink – Find your study buddy

A mobile-first web app that matches students by subject and availability, lets them join or host study sessions, and keeps them consistent with a daily study streak.

## Problem
Students study alone, struggle to find someone studying the same subject at the same time, and lose motivation.

## Target users
High school and university students.

## Features
- **Profile:** choose subjects and free times
- **Buddy matching:** ranked by match percentage
- **Study sessions:** join or host sessions
- **Streak tracker:** daily check-in with a 7-day view

## Tech stack
HTML, CSS and vanilla JavaScript in a single file. Data is saved in the browser with localStorage. No build step and no dependencies.

## Run locally
Open `index.html` in a browser.

## Deploy
- **Vercel / Netlify:** import this repo, with no build command and the root as the output directory.
- **GitHub Pages:** Settings, then Pages, then deploy from the `main` branch.

## Roadmap
User accounts, real-time chat, campus verification, and a database backend.
